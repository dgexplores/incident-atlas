# Demonstrate and explain this project

1. Open the demo. Replay database pressure; inspect the five findings, dependency grouping and uncertainty disclaimer.
2. Replay the healthy baseline. No incident should be created.
3. For measured data, run the local collector described in the README, then upload its JSON. A functioning Docker daemon is required. A file upload does not prove measurement provenance.
4. Inspect the frozen baseline, sample interval and finding IDs. Record an investigating/resolved review and confirm it remains in this browser session.
5. Model assistance is optional: configured provider + operator token, explicit request, checked evidence/runbook IDs. No raw logs or autonomous remediation.

Explain: why median/MAD, why three consecutive breaches, why multicore CPU is not capped at85%, how dependency grouping works, and why correlation is not causal proof.

Failure exercise: upload a duplicate or incomplete stream. It must be refused with validation feedback. Do not represent generated fixtures as Docker captures.
