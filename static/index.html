Bring your own container signals.

Collect CPU and memory measurements on your machine, then upload the JSON capture. This web service never accesses your Docker socket.

Collection instructions

Run from the project folder with Docker running. Replace my-container with your container name. The first 50 samples establish a baseline; collect a representative healthy workload first.

python -m atlas.collector my-container --samples 70 --interval 5 --output telemetry.json

No credentials or logs are collected. CPU values can exceed 100% on multiple cores. Sample indices are not wall-clock minutes.
